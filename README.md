
# 🐾 PawPath – Pet Adoption & Fostering Platform

PawPath is a web-based platform designed to connect people interested in pet adoption and fostering with available pets and animal shelters.

## 📌 Project Overview

PawPath aims to make pet adoption and fostering more accessible through an organized online platform.

## ⚙️ Installation & Setup

1. Install XAMPP.
2. Clone or download this repository.
3. Place the project folder inside `htdocs`.
4. Start Apache and MySQL from XAMPP.
5. Open phpMyAdmin.
6. Create a database and import `pawpath.sql`.
7. Update the database connection settings in the project.
8. Open your browser and visit:

```text
http://localhost/PawPath/
```
